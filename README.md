# Bilingo Bonus Box

Static teaching-materials site for Bilingo teachers, hosted at
https://bilingo-xian.github.io/

Plain HTML/CSS/JS — no build step, no frameworks. See **CHEATSHEET.md** for
how to edit and publish (it's on Alex's Mac, ignored by git).

- `index.html` — books menu
- `GE3.html` — the whole GE3 book (units + 20 lessons, hash-routed)
- `assets/` — styles, scripts, logo
- `content/GE3/` — games (`game.html`) and pictures; videos live on DingTalk drive
- `tests/` — unit test PDFs
- `legacy-site/` — the previous React/Vite version, kept for reference only
