Teacher notes & controls

Flow: explore the hidden picture → child guesses and produces the “I go…” sentence → click Word said — uncover! Optional: reveal the worker question → child answers orally → click Answer said — send worker!

Revealing the picture does not reveal any sentence. Each language button is a show/hide toggle. Hide language closes all three. Every new place starts with all language hidden.

Window: starts at 36 scene-pixels in diameter. Slow grow increases the diameter by about 1.3 scene-pixels per second. You can resize it manually at any time. Each new place resets it to tiny. The slow-grow setting carries over between places.

Locations: bakery, fire station, office, police station, post office, shop, farm, hospital, library, school, park. Every shuffled tour includes all 11 once. The final Next button starts a fresh shuffled tour.

Articles: “I go to the library / the park / the hospital,” but “I go to school” for attending school. Worker questions use “in the…” except “on the farm” and “at school.” Answers include “An office worker…” and “A librarian…”

The park's example worker is a gardener. Other sensible oral answers can be accepted by the teacher; this activity does not judge speech. Each uncovered place earns one star; sending its worker earns one more.

Offline artwork and synthesized sound effects are built in. Scores last for this browser session. If sound is unavailable, the activity still works silently.
